## 가변 객체와 불변 객체
- **불변 객체**(immutable)
	- 메모리 안에 담겨 있는 값이 언제나 변하지 않는 객체를 의미한다.
	- `int` & `bool`, 실수형(float), 문자형(str), 튜플(()), 바이트형, range형, 복소수형(complex), frozenset, Decimal 등
- **가변 객체**(mutable)
	- 리스트, set, 딕셔너리, 바이트 배열, class(불변 객체로 정의 가능하지만 보통 가변이다.), np.array는 값은 변경 가능하지만 크기는 변경 불가능

## 얕은 복사와 깊은 복사
**가변 변수의 복사**
```python
>>> a = [1, 2, 3]
>>> b = a # 참조 복사
>>> b[0]= 5
>>> a
[5, 2, 3]
>>> b
[5, 2, 3]
>>> id(a)
4396179528
>>> id(b)
4396179528
```
- a를 할당하고 b에 a를 할당하면 a와b가 같은 메모리 주소를 바라보면서 복사가 된다.
- 이를 보면 예상하겠지만 **b값을 바꾸면 a도 바뀐다.** 왜냐하면 가변 변수는 메모리 내의 값이 변경 가능한데 b를 활용하여 값을 변경햇으니 **메모리 내의 값이 변경이 되었고 같은 메모리를 바라보는 a도 값이 바뀌는 것** 이다.
- 이를 **`참조 복사`라고 하며 가변 객체를 다룰 때 항상 조심해야한다.**
**불변 변수의 복사**
```python
>>> a = "abc"
>>> b = a
>>> a
'abc'
>>> b
'abc'
>>> id(a)
4387454680
>>> id(b)
4387454680
>>> b = "abcd"
>>> a
'abc'
>>> b
'abcd'
>>> id(a)
4387454680
>>> id(b)
4396456400
```
- 불변 변수의 복사를 확인해 보자
- b에 a를 할당하면 a, b 둘 다 같은 값을 가지면서 같은 메모리 주소를 바라본다.
- 거기에 b에 다른 값을 할당하거나 `replace()`를 사용하여 값이 변경되면 메모리 재할당이 이루어지며 주소가 변경된다.
- 즉 불변은 복사를 해도 값이 변경되면 복사를 풀고 다른 메모리를 할당 받는다.(메모리 안을 수정 못하니까)
- 즉 불변 객체는 참조 복사를 해도 값이 바뀌는 순간 메모리 안이 바뀌는게 아닌 다른걸 바라보기 때문에 문제가 없다.

### 얕은 복사
- 그럼 복사를 할때는 같은 걸 두 개 놔두고 변경했을 때 변경된걸 찾고 싶어 같은 값을 가진 두 객체가 필요한 경우가 있다.
- 이 때 **얕은 복사, 깊은 복사를 사용한다.**
```python
>>> a = [1,2,3]
>>> b = a[:]
>>> id(a)
4396179528
>>> id(b)
4393788808
>>> a == b
True
>>> a is b
False
>>> b[0] = 5
>>> a
[1, 2, 3]
>>> b
[5, 2, 3]
```
- 위 방식으로 보면 그냥 복사가 아닌 `슬라이싱`을 통해 복사를 진행하면 같은 값이지만 다른 메모리를 할당 받은 걸 알 수 있다.
- 하지만 **위 슬라이싱을 또한 완전한 복사에 해당하지 않는다.**
- 리스트안의 리스트 가변 객체 안에 가변 객체인 경우 문제가 된다.
```python
>>> a = [[1,2], [3,4]]
>>> b = a[:]
>>> id(a)
4395624328
>>> id(b)
4396179592
>>> id(a[0])
4396116040
>>> id(b[0])
4396116040
```
- 바깥 리스트는 복제 되어 새로운 메모리를 할당 받았지만 안쪽 리스트는 재할당을 받은 상태가 아니기에 이중리스트 일때는 `슬라이싱`을 이용한 얕은 복사도 완벽하게 복사하진 않는다.
```python
>>> a[0] = [8,9]
>>> a
[[8, 9], [3, 4]]
>>> b
[[1, 2], [3, 4]]
>>> id(a[0])
4393788808
>>> id(b[0])
4396116040
```
- 위와 같이 내부 리스트(내부 객체)에 재할당`=`을 하는 경우는 이제 메모리가 재할당 되는 것을 볼 수 있다.
```python
>>> a[1].append(5)
>>> a
[[8, 9], [3, 4, 5]]
>>> b
[[1, 2], [3, 4, 5]]
>>> id(a[1])
4396389896
>>> id(b[1])
4396389896
```
- 하지만 **재할당`=`이 아닌 수정, 추가, 삭제를 하는 경우는 메모리가 재할당 되는 작업이 아니기에 아직 같은 값을 바라보고 있어 둘 다 변한다.**
- 즉 얕은 복사는 새로운 껍데기(리스트 등)를 만들어서 원본의 요소들을 가져오는데, 그 안에 **또 다른 리스트(중첩 객체)** 가 있으면 그건 알맹이를 복사하는 게 아니라 주소만 가져온다.
- 대표적인 얕은 복사 모듈은 `from copy import copy`가 존재한다.
### 깊은 복사
- 그럼 완전한 복사 같은 값을 들고오지만 전혀 다른 메모리 주소를 가지는 객체는 어떻게 만드냐?
- 얕은 복사에 사용한 copy 패키지의 deepcopy를 사용하면 된다.`from copy import deepcopy`
```python
>>> import copy
>>> a = [[1,2],[3,4]]
>>> b = copy.deepcopy(a)
>>> a[1].append(5)
>>> a
[[1, 2], [3, 4, 5]]
>>> b
[[1, 2], [3, 4]]
```
- 이렇게 하면 그냥 복사를 해도 내부 객체를 변경해도 외부 객체를 변경해도 모든 객체가 다른 메모리 주소를 바라보기에 값을 변경해도 다른 객체가 변경되지 않는다.
