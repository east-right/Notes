- 컴프리헨션은 내가 학부생때 뭐 한줄 for문 혹은 한 줄 for/if문으로 공부했다.
	- `[i for i in range(10)]` 이거다.
- 가장 큰 장점중 하나는 한 줄로 적기에 파이써닉하고 읽기 쉽습니다.
- 컴프리헨션을 사용이 가능한 구조는 아래와 같다.
	- 리스트
	- 딕셔너리
	- 셋
	- 제네레이터 표현식 -> 지금 이거 적는 이유
- 한 줄로 for문을 이용해 위 데이터 셋을 만들 수 있다.
## 리스트 컴프리 헨션
- `[i for i in range(10)]` -> 가장 기본적인 형태
- `[i for i in range(10) if i%2 == 1]` -> for if문 형태(else문 안쓰는 형태)
- `[i if i%2 == 1 else i+1 for i in range(10)]` -> for if 문 형태(else도 쓰는 형태)
## 딕셔너리 컴프리헨션
- `names = ["alice", "bob", "chris"]` -> 베이스 데이터
- `name_length = {name: len(name) for name in names}` -> 가장 기본적인 형태
	- 결과: `{'alice': 5, 'bob': 3, 'chris': 5}`
- `{name: len(name) for name in names if len(name) >= 4}` ->if문 사용
	- 결과: `{'alice': 5, 'chris': 5}`
- `{name: 'pass' if len(name) >= 4 else 'drop' for name in names}` -> if-else 사용
	- 결과: `{'alice': 'pass', 'bob': 'drop', 'chris': 'pass'}`
### 셋 컴프리헨션
- 셋은 `{1,2,3}` 형태로 만약 `[1,2,3,3]` 값이 셋으로 바뀌면 왼쪽 처럼 중복이 사라진다는것만 알면 다른거 없다.

## Iterable과 Iterator
**iterable**
- iterable 객체 - 반복 가능한 객체
- 대표적으로 iterable한 타입 - list, dict, set, str, bytes, tuple, range
**iterator**
- iterator 객체 - 값을 차례대로 꺼낼 수 있는 객체
- iterator는 iterable한 객체를 내장함수 또는 iterable객체의 메소드로 객체를 생성
- 파이썬 내장함수 `iter()`를 사용해 iterator 객체 생성가능
- 그 오라클의 fetch와 같다고 보면 된다. 
```python
>>> a = [1, 2, 3]
>>> a_iter = iter(a)
>>> type(a_iter)
<class 'list_iterator'>
-------------------------
>>> next(a_iter)
1
>>> next(a_iter)
2
>>> next(a_iter)
3
>>> next(a_iter)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
StopIteration
```
- 즉 값을 하나 씩 꺼내서 확인 가능하다.
	- 당장 이렇게 보면 뭐 스택/큐 라는 거냐? 라고 생각할 수 있는데 조금 다르다.
		- 스택과 큐는 명시적으로 내가 값을 집어 넣고`pop()`으로 뺍니다. 즉 **내가 이번 시점의 값을 받아 본다 = 리스트에서 값을 들고 나온다 = 리스트에선 방금 뽑은 값 삭제**
		- `iter()`은 데이터가 리스트에 있든, 실시간으로 생성이 되든 그저 다음 값이 뭔지 "보고 싶다"인 것 이다. 즉 `next()`로 다음 값을 받아봐도 그 리스트 기준 리스트 안의 값이 사라지는게 아닌 바라보는 인덱스가 바뀐 것 이다.
			- 그니까 일반 리스트 `a[0], a[1]`를 순차적으로 보는 걸 `next()` 만으로 저 인덱스 숫자를 증가 시킨다는 것 이다. 
- `iter`은 `next(iter(a))`로만 다음 값을 받아 볼 수 있다.
**직접 구현으로 이해하기**
```python
class MyIterator:
    def __init__(self, data):
        self.data = data
        self.index = 0

    def __iter__(self):
        return self  # 이터레이터 객체 자신을 반환

    def __next__(self):
        if self.index >= len(self.data):
            raise StopIteration  # 더 이상 반환할 값이 없으면 예외 발생
        value = self.data[self.index]
        self.index += 1
        return value

# 이터레이터 사용
my_iter = MyIterator([1, 2, 3])
for item in my_iter:
    print(item)
```
- 위는 직접 구현한 것 이다. 이걸 보면 이해가 빠를 것 이다.
>[!코드 해석과 내장 함수도 되고 매직 매서드도 되는 이유(덕 타이핑)]
>위 코드는 함수`iter()`의 간단한 구현 버전이다. 실제론 리스트에 저 `iter`내장 함수를 사용하면 매직 매서드에 보면  `__next__` 이 존재하는걸 확인 가능하다. 
>
>또한 리스트를 만들고 `dir(list)`를 하면 매직 매서드가 보이는데 거기에 `__iter__` 매서드 함수가 있는 걸 확인 가능하다.
>
>이게 무슨 의미냐 파이썬 내장 함수`iter()`는 얘가 iter 작업을 하는게 아닌 클래스 안 즉 리스트 라는 클래스 안에  `__iter__`가 존재하면 실행 시키는 것 이다.
>
>즉 `next()` 도 마찬가지로 `iter()` 함수 안에 매직 매서드가 `__next__`가 존재해서 `.__next__()`를 써도 `next()`를 써도 같은 행동이 실행되는 것 이다.
>
>참고로 for 문도 위와 같은 작업을 진행하는데 1. `__iter__`이 있는지 확인 2. `__next__`를 반복 실행이다. 즉 for 문은 iterable(리스트)을 iterator로 바꾸고 next로 꺼내는 것 이다. 

## 제네레이터
- 제네레이터도 iterator과 같이 값을 순차적으로 꺼낼 수 있는 객체이다. 즉 iterator의 하위 개념? 느낌이라고 보면 된다.
- 하지만 **구현 방식과 사용방식에 차이를 보인다.**
- 제네레이터를 구현하기 위해서 알아야 하고 사용하는 건 `yield`이다.
	- 이건 함수에 사용되며 return 대신 사용된다.
- 함수 내에서 `yield`를 만나면, 해당 값을 반환하고 함수의 실행을 일시 중지하고, 다음에 다시 호출되면, 중지되었던 지점부터 다시 실행을 재개한다.
**yield 키워드의 동작**
- **값 반환:** `yield` 문은 함수 실행 중 값을 반환합니다. `return` 문과 유사하지만, `return`은 함수를 종료시키는 반면, `yield`는 함수의 상태를 저장하고 일시 중지합니다.
- **실행 중지 및 재개:** `yield`를 만나면 함수는 해당 값을 반환하고 실행을 일시 중지합니다. 제너레이터가 다시 호출(`next()` 함수 사용)되면, 중지되었던 `yield` 문 다음부터 다시 실행을 시작합니다.
```python
def simple_generator():
    yield 1
    yield 2
    yield 3

# 제너레이터 객체 생성
gen = simple_generator()

# 제너레이터 사용
print(next(gen))  # 출력: 1
print(next(gen))  # 출력: 2
print(next(gen))  # 출력: 3
# print(next(gen))  # StopIteration 예외 발생

# 혹은
gen = simple_generator()
for item in gen:
	print(item) #출력: 1, 출력: 2, 출력: 3 
```
- `simple_generator()` 함수는 1,2,3을 순차적으로 반환하는 함수
- `next(gen)`을 호출할 때마다 `yield` 문을 만나 값을 반환하고, 함수는 일시 중지된다. 다음 `next(gen)` 호출 시 중지되었던 지점부터 다시 실행된다.
- 더 이상 반환할 `yield`가 없으면 `StopIteration` 예외가 발생한다.

## 제네레이터의 장단점
**장점**
- **메모리 효율성:** 값을 미리 생성하여 메모리에 저장하지 않고, 필요할 때마다 하나씩 생성하므로 메모리 사용량이 적다. 특히, 매우 큰 데이터 시퀀스를 다룰 때 유용합니다.
- **지연 평가 (Lazy Evaluation):** 값이 실제로 필요할 때까지 계산을 미루므로, 불필요한 계산을 줄일 수 있다.
- **코드 간결성:** 이터레이터를 직접 구현하는 것보다 코드가 간결하고 가독성이 좋다.
- **자동 상태 관리:** 제너레이터는 자동으로 함수의 상태(로컬 변수, 실행 위치 등)를 저장하고 복원하므로, 개발자가 직접 상태를 관리할 필요가 없다.

**단점**
- **단방향:** 제너레이터는 한 번 순회하면 끝. 다시 순회하려면 새로운 제너레이터 객체를 생성해야 한다.(이터레이터는 `__iter__()`를 다시 호출하여 초기화할 수 있다.)
- **제한적인 기능:** 클래스 기반 이터레이터만큼 복잡한 로직을 구현하기는 어렵다. (하지만 대부분의 경우 제너레이터로 충분.)


## 제네레이터 표현식
- 이 글을 적는 가장 근본적인 이유가 나왔다. 한번도 사용해본적 없고 응용법도 다양한 방법이다.
- 기본적으로 리스트 컴프리헨젼은 모든 결과를 리스트로 만들어서 메모리에 저장한다.
- 하지만 `()`로 한 제네레이터 표현식은 한번에 계산이 아닌 필요할 때 하나씩 꺼내서 사용한다.
- 즉 위 제네레이터를 `def`와 `yield`로 복잡하게 만드는 것이 아닌 **제네레이터 컴프리헨션** 인 것이다.
![](assets/Pasted%20image%2020260427200958.png)
- 보면 리스트는 결과가 계산되어서 나온게 보이지만 제네레이터는 아직 모듈 형태로 존재만 하고 값을 반환하지 못한다.
- 이 때 제네레이터 처럼 `next()`를 쓰거나 `for`문을 사용해서 사용가능하다.

## yield from(python 3.3 이상)
- yield from은 다른 제너레이터나 이터러블 객체로부터 값을 가져와 yield 할 때 유용하다.
```python
def chain_generators(gen1, gen2):
    yield from gen1
    yield from gen2

# 두 개의 제너레이터
gen1 = (i for i in range(3))
gen2 = (i for i in range(3, 6))

# 제너레이터 연결
chained_gen = chain_generators(gen1, gen2)

for value in chained_gen:
    print(value)  # 0, 1, 2, 3, 4, 5 출력
```
- yield from을 사용하면 중첩된 루프 없이도 여러 제네레이터/이터러블을 합쳐서 순차적으로 가져 올 수 있는 코드가 구현 가능하다.

## yield 키워드의 실행 방식
**`yield` 키워드의 핵심 동작: 중단과 반환**
- yield 키워드는 제네레이터 함수 내에서 다음과 같은 두 가지 핵심 역할을 수행한다.
	1. 키 반환(Return Value)
		- yield 문은 return문 처럼 함수 실행중 에 값을 반환한다.
		- return은 함수를 완전히 종료하고 값을 반환하는 반면, yield는 값을 반환하더라도 **함수의 상태(로컬 변수, 실행 위치 등)를 그대로 유지한다.**
	2.  실행 중단(Suspend Excution)
		- yield 문을 만나면, 제네레이터 함수는 실행을 일시 중지한다.
		- 함수의 실행은 yield 문 바로 뒤에서 멈추고, 제네레이터의 제어권은 호출자에게 넘어간다.
		- 이때, 함수의 로컬 변수와 현재 실행 위치 등의 상태는 메모리에 그대로 보존된다. 일시정지 버튼을 누른 것과 똑같다.
**재개**
- 제네레이터가 다시 next() 함수 혹은 for 문으로 호출이 되면, 중단되었던 yield 문 다음 코드 부터 실행을 재개한다.
- 함수는 이전 상태를 기억하고 있기 때문에, 마치 중단되지 않았던 것처럼 자연스럽게 다음 코드를 실행한다.
**예제: 무한수열**
```python
def infinite_sequence():
    num = 0
    while True:
        yield num
        num += 1

gen = infinite_sequence()

print(next(gen))  # 0
print(next(gen))  # 1
print(next(gen))  # 2
# ... 무한히 많은 값을 생성 가능
```
- `infinite_sequence` 함수는 `yield`를 통해 무한히 증가하는 숫자를 생성한다.
- `next(gen)`을 호출할 때마다 새로운 숫자를 반환하고, 함수는 다음 호출을 위해 대기 상태가 된다.
- 일반적인 함수였다면 무한 루프에 빠지겠지만, 제너레이터는 `yield` 덕분에 필요할 때마다 값을 생성하고 중단하는 것을 반복할 수 있다.
