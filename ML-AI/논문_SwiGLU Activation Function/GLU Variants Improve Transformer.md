#DNN #LLM #활성화함수 
wiGLU 는 Swish 와 Gated Linear Unit(GLU)의 아이디어를 결합한 활성화 함수이다.

Google PaLM 그리고 Llama3 와 같은 대형 언어 모델에서 사용된다.

## 1. SwiGLU의 정의

SwiGLU는 다음과 같은 수식으로 정의 된다.

![](assets/Pasted%20image%2020250421192010.png)

이 함수는 다음과 같은 두 요소로 구성된다.

- Swish 함수 : Swish 는 $x \cdot \sigma(\beta x)$ 로 정의되며, 이는 입력을 시그모이드 함수로 gating 하여 일정 부분만 전달한다. 이 부분은 ReLU와 같은 기존 함수보다 더 매끄러운 곡선을 가지며, 학습 과정에서 더 안정적인 성능을 보여준다.
- GLU의 gating 메커니즘 : GLU는 시그모이드 함수를 활용해 입력에 게이트를 적용해 중요도를 조절한다. $W \cdot x$ 와 $V \cdot x$ 를 사용해 더 강력한 게이팅 메커니즘을 사용하여 정보 흐름을 조절하여 중요한 정보를 강조하고 불필요한 정보는 줄이는 역할을 한다.

## 2. SwiGLU의 특징과 장점

- 비선형성과 유연성 : Swish 와 GLU의 결합으로 인해 SwiGLU는 단순한 ReLU 나 다른 활성화 함수보다 더 부드러운 **비선형성을 가지고 있어 복잡한 패턴을 더 잘 학습할 수 있다.**
- 기울기 소실 방지 : SwiGLU 는 기울기 소실 문제를 줄여주어 깊은 신경망에서도 안정적인 학습을 가능하게 한다. **Swish의 부드러운 곡선은 기울기가 완전히 사라지지 않게 해주며, GLU의 gating 메커니즘이 학습 중 중요한 정보가 손실되지 않도록 돕는다.**
- 빠른 수렴 속도 : SwiGLU는 더 효과적으로 정보를 전달하면서도 비선형성을 유지하기 때문에 학습 과정에서 더 빠르게 수렴할 수 있다.

## 3. 다른 Activation Function

- **GLU** : 선형성과 비선형성을 결합한 게이팅 메커니즘으로 시작
- **Bilinear GLU** : 더 단순한 계산을 위한 시그모이드 제거 버전
- **ReGLU** : 시그모이드 대신 ReLU를 사용하여 계산 효율성을 높임
- **GEGLU** : 더 부드러운 기울기를 제공하는 GELU 도입
- **SwiGLU** : Swish 함수를 이용해 대규모 모델에서 뛰어난 성능을 발휘

이러한 활성화 함수들은 각기 다른 상황에 맞춰 사용되며, 모델의 성능을 높이기 위한 다양한 실험과 개선을 거쳐왔다. GLU의 게이팅 메커니즘은 데이터를 선별적으로 전달하여 학습 효율을 높이며, 이를 기반으로 한 변형들은 더 간단하거나 더 강력한 비선형성을 추가하여 모델의 표현력을 극대화하는 방향으로 발전해왔다.
