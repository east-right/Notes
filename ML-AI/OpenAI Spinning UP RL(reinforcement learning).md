>[!외부 환경(external environment)이란 뭘까?]
>이 부분은 따로 나와있지 않아서 GPT에게 물어본 결과를 기록한다.
>external environment(외부 환경)"이라는 용어는 강화학습이나 에이전트가 환경과 상호작용하는 맥락에서 자주 등장하는 개념입니다. 외부 환경은 에이전트의 내부 추론이나 사고 과정과는 구분되는, 에이전트가 실제로 영향을 주고받는 세계나 시스템을 의미합니다.
>### 외부 환경에 대한 해석
>1. **강화학습 맥락에서의 외부 환경**:
>	- **상태와 관찰**: 에이전트는 외부 환경으로부터 관찰(observation)을 받고, 현재 상태(state)를 파악합니다.
>	- **행동의 결과**: 에이전트가 취한 행동(action)은 외부 환경에 영향을 주며, 그 결과로 다음 관찰이나 보상(reward)을 받게 됩니다.
>	- **예시**: 로봇이 방 안을 탐색하는 경우, 방 안의 물체들, 장애물, 목표 지점 등이 외부 환경에 해당합니다. 또는 게임 에이전트라면 게임의 규칙과 상태, 다른 플레이어 등이 외부 환경입니다.
>2. **ReAct 논문 맥락에서의 외부 환경**:
>	- ReAct에서는 에이전트가 언어적 추론(thought)을 수행할 때, 이 추론 행동은 외부 환경에 직접적인 영향을 주지 않습니다. 즉, 단순히 내적 상태(컨텍스트)를 업데이트할 뿐입니다.
>	- **외부 환경**은 에이전트의 언어적 추론과는 구별되며, 에이전트의 실제 행동(예: Act 1, Act 2 등)이 영향을 미치는 세상이나 시스템을 말합니다. 여기에는 에이전트가 질문에 답하거나, 물체를 조작하거나, 데이터를 검색하는 등의 실제 상호작용 대상이 포함됩니다.
>
>결론적으로, "external environment"는 에이전트가 직접적으로 상호작용하고 영향을 주고 받는 모든 외부 세계 또는 시스템을 의미합니다. 이는 에이전트의 내부 추론 단계와는 별개로, 실제 행동을 통해 변화를 이끌어내는 대상이라고 이해하면 됩니다.
