# 요약
- Relative Positional Encoding(상대 위치 인코딩) 논문
- 기존 Transformer는 단어의 순서를 나타내기 위해 **절대 위치 인코딩**(e.g. sinusoidal positional encoding)을 사용.
- 하지만 이는 문장 내 **상대적인 위치 정보**를 학습하기에 비효율적이며, 문장 길이에 따라 일반화가 잘 되지 않는 문제가 있음.
- **Self-attention** 연산 내에서 각 쿼리-키(query-key) 계산에 **상대 위치 벡터**를 직접 더해줌으로써, 단어 간의 상대적 거리 정보를 반영함.
- 즉, “나로부터 1단어 뒤”라는 상대적인 개념이 attention score 계산에 직접 반영됨.
- **문장 구조를 반영**: “어떤 단어 앞에 있는지, 뒤에 있는지”라는 정보는 문장의 의미 해석에 핵심적입니다.
- **일반화 성능 향상**: 절대 위치가 아니라 상대 위치를 쓰면 더 다양한 길이의 문장에 대해 robust하게 학습 가능

## 0.Abstract
Transformer는 구조에서 상대적 또는 절대적 위치 정보를 명시로으로 모델링 하지않고, 대신 입력에 절대적 위치 정보를 추가한다. 이 논문에서는 self-attention 메커니즘을 확장하여 시퀀스 요소들 간의 상대적 위치나 거리 정보를 효율적으로 고려하는 방법을 제시한다.

## 1. Introduction
순환 신경망(RNN)은 일반적으로 시간 t에서의 입력과 이전의 은닉 상태 $h_{t-1}$을 함수로 사용하여 은닉 상태 $h_{t}$를 계산함으로써, 순차적 구조를 통해 시간 축에서 상대적 및 절대적 위치를 직접적으로 포착한다. 비순환 모델의 경우는 입력 요소를 순차적으로 고려하지 않기 때문에, 시퀀스 순서를 사용할 수 있도록 명시적으로 위치 정보를 인코딩해야 할 수도 있다.

일반적인 접근법 중 하나는 위치 인코딩을 사용하여 입력 요소와 결합함으로써 모델이 위치 정보를 인식할 수 있도록 하는 것이다.

합성곱 신경망(CNN)은 본질적으로 각 합성곱의 커널 크기 내에서 상대적 위치를 포착하지만, 위치 인코딩을 사용하면 성능이 더욱 향상되는 것으로 나타났다.

한편, Transforemr는 합성곱이나 반복 구조를 사용하지 않기 때문에 위치 정보의 명시적 표현을 포함하는 것이 특히 중요하다. 따라서 attention 기반 모델들은 위치 인코딩이나 거리 기반의 편향된 attention 가중치를 사용하여 시퀀스 순서를 반영하도록 한다.

이 연구에서는 Transformer의 self-attention 메커니즘에 상대적 위치 표현을 효율적으로 포함시키는 방법을 제시한다.

## 2. Background
### 2.1 Transformer
다양한 주파수의 sinusoidal(정현파) 함수에 기반한 위치 인코딩이 첫 번째 레이어 이전에 인코더와 디코더의 입력 요소에 추가된다. 학습된 절대 위치 표현과는 달리, 저자들은 sin 위치 인코딩이 모델이 상대적 위치에 따라 attention을 학습할 수 있게 해줌으로써 학습 중에 보지 못한 시퀀스 길이에도 일반하는데 도움이 될 것이라고 가정했다. 이 속성은 절대 위치 인코딩과 달리 전체 시퀀스 길이에 영향을 받지 않는 상대적 위치 표현에도 적용된다. Residual connections는 위치 정보를 상위 레이어로 전파하는 데 도움을 준다.

### 2.2 Self-Attention
Self-attention 서브레이어는 h 개의 attention 헤드를 사용한다. 서브레이어 출력을 생성하기 위해 각 헤드에서 나온 결과를 이어 붙이고, 파라미터화된 선형 변환을 적용한다.

각 attention 헤드는 n개의 요소로 구성된 입력 시퀀스 x = ($x_{1}$, …, $x_{n}$)에 대해 동작하며, $x_{i} \in \mathcal{R}^{d_{x}}$이다. 이 헤드는 동일한 길이의 새로운 시퀀스 z = ($z_{1}$, …, $z_{n}$)를 계산하며, 여기서 $z_{i} \in \mathcal{R}^{d_{z}}$이다.

각 출력 요소 $z_{i}$는 선형 변환된 입력 요소들의 가중합으로 계산된다.

($x_{j}W^{V}$는 입력 토큰과 가중치 행렬을 곱하여 선형 변환을 적용한 값, 이 선형 변환은 입력 벡터의 정보를 새로운 벡터 공간으로 변환함)

![](assets/Pasted%20image%2020250420193249.png)

여기서 각 가중치 계수 $\alpha_{ij}$는 소프트맥스 함수를 통해 계산된다.

($\alpha_{ij}$는 입력 토큰이 출력 토큰 $z_{i}$에 기여하는 가중치 값으로 attention 메커니즘을 통해 계산됨)

![](assets/Pasted%20image%2020250420193259.png)

그리고 $e_{ij}$는 두 입력 요소를 비교하는 유사도 함수(compatibility function)를 사용하여 계산된다.

(지수함수(exp)를 사용하면 음수가 아닌 확률값을 구할수 있고, 높은 유사성 점수에 대한 기하급수적 강조)

![](assets/Pasted%20image%2020250420193315.png)

유사도 함수로 스케일된 내적(scaled dot product)을 선택하여 효율적인 계산이 가능하도록 했다. 그리고 입력의 선형 변환은 충분한 표현력을 제공하게 된다.

여기서 $W^{Q}, W^{K}, W^{V} \in \mathcal{R}^{d_{k} * d_{z}}$는 파라미터 행렬이며, layer와 attention 헤드마다 고유한 행렬을 사용한다.

## 3. Proposed Architecture

### 3.1 Relation-aware Self-Attention
논문에서는 self-attention을 확장하여 입력 요소들 간의 쌍(pairwise) 관계를 고려하는 방법을 제안한다.

입력 요소 $x_{i}$와 $x_{j}$ 사이의 엣지(문장에서 몇 단어 떨어져 있는지와 같은 상대적 위치 정보를 나타냄)는 벡터 $a^{V}_{ij}$,$a^{K}_{ij}$ $\in \mathcal{R}^{d_{x}}$로 표현된다. 두 가지 별개의 엣지 표현을 학습하는 이유는 추가적인 선형 변환 없이 사용 가능하기 때문이다. 이 표현들은 attention 헤드들 간에 공유된다. 그리고 $d_{a} = d_{z}$로 설정한다.

엣지 정보를 서브레이어에 출력에 전파한다.

![](assets/Pasted%20image%2020250420193331.png)

이러한 방식은 특정 attention 헤드에 의해 선택된 엣지 타입에 대한 정보가 다운스트림(이후 레이어) 인코더 또는 디코더 레이어에 유요한 작업에서 중요할 것이다.

또한 유사도를 결정할 때 엣지를 고려하기 위해 식을 수정했다.

### 3.2 Relative Position Representations

선형 시퀀스의 경우, 엣지는 입력 요소들 간의 상대적 위치 차이에 대한 정보를 포착할 수 있다. 논문에서 고려하는 최대 상대적 위치는 절대값이 k인 최대값으로 클리핑된다. 이것은 특정 거리 이상에서는 정확한 상대적 위치 정보가 유용하지 않다고 가정한다. 최대 거리를 클리핑함으로써 학습 중에 보지 못한 시퀀스 길이에도 모델이 일반화할 수 있게 된다. 따라서 총 2k + 1 개의 고유한 엣지 레이블을 고려한다.

![](assets/Pasted%20image%2020250420193422.png)

그 후, 상대적 위치 표현을 학습하게 되며, 이 표현은 $w^{K} = (w^{K}_{-K},...., w^{K}_{k})$와 $w^{V} = (w^{V}_{-K},...., w^{V}_{k})$로 구성되며, 여기서 $w^{K}_{i}$ 와 $w^{V}_{i}$는 $\mathcal{R}^{d_{a}}$에 속한다.

### 3.3 Efficient Implementation

입력 요소들 간의 엣지를 고려할 때, 공간 복잡도 문제가 발생할 수 있다. 길이가 n이고 h개의 attention 헤드를 가진 시퀀스의 경우, 상대적 위치 표현을 각 헤드에 공유하여 저장함으로써 저장 공간 복잡도를 $O(hn^2d_{a})$에서 $O(n^2d_{a})$로 줄인다. 또한, 상대적 위치 표현은 시퀀스 간에 공유될 수 있다. 따라서 전체 self-attention의 공간 복잡도는 $O(bhnd_{z})$에서 $O(bhnd_{z} + n^2d_{a})$로 증가한다. 여기서 $d_{a} = d_{z}$라고 가정하면, 상대적 증가의 크기는 $\frac{n}{bh}$에 따라 달라진다.

Transformer는 모든 시퀀스, 헤드 및 위치에 대해 self-attention을 효율적으로 계산하기 위해 병렬 행렬 곱셈 연산을 사용한다. 상대적 위치 표현을 사용하지 않을 때는, 각 $e_{ij}$는 bh개의 $n \times d_{z}$ 와 $d_{z} \times n$ 행렬의 병렬 곱셈으로 계산할 수 있다. 각 행렬 곱셈은 특정 헤드와 시퀀스가 모든 시퀀스 위치에 대해 $e_{ij}$를 계산한다. 어떤 시퀀스나 헤드에 대해, 각 위치는 다른 위치들과의 유사도 계산에서 동일한 표현을 사용하게 된다.

상대적 위치를 고려할 때는 각 위치 쌍마다 서로 다른 상대적 위치 표현이 필요하기 때문에, 모든 위치 쌍에 대해 $e_{ij}$를 단일 행렬 곱셈으로 계산할 수 없다. 또한 상대적 위치 표현을 broadcasting하는 것도 피해야 한다. 그러기 위해서는 위에서 사용했던 식을 두 항으로 분리함으로써 이 문제들을 해결할 수 있다.

(broadcasting 문제 : 상대적 위치 표현을 계산할 때, 모든 위치 쌍에 대해 같은 방식으로 값을 반복해서 사용할 수 없기 때문에 브로드캐스팅 처럼 같은 값을 여러 위치에서 복사하여 적용하는 방식을 피해야 한다는 의미)

![](assets/Pasted%20image%2020250420193434.png)

첫 번째 항은 이전 처럼 동일하게 계산하고, 상대적 위치 표현이 포함된 두 번째 항은 텐서 재구성을 통해 n개의 병렬 곱셈을 $bh \times d_{z}$ 와 $d_{z} \times n$ 행렬로 수행할 수 있다. 각 행렬 곱셈은 특정 시퀀스 위치에 대해 모든 헤드와 배치에 해당하는 $e_{ij}$에 기여하며, 추가적인 재구성을 통해 두 항을 더할 수 있다.

- **Query 벡터 행렬**은 $(bh \times n) \times d_{z}$ 크기이며, 각 행은 하나의 Query 벡터
- **상대적 위치 정보 행렬**은 $d_{z} \times n$ 크기이며, 각 열은 하나의 상대적 위치 정보 벡터
- 두 행렬을 곱하여 최종 $bh \times n \times n$ 크기의 유사도 행렬을 얻음
