#LLM #DNN #활성화함수

> **LSTM 및 RNN 에서 gate는 정보 흐름을 명시적으로 제어한다.**
> 
> - 입력 게이트 : 메모리 셀에 추가되어야 하는 새 입력의 양을 제어함
> - 출력 게이트 : 셀의 어떤 정보를 다음 레이어로 출력할지 결정함
> - Forget Gate(LSTM에만 해당) : 메모리 셀에서 어떤 정보를 버려야 하는지 결정함
> 
> self-attention에서는 전통적인 의미의 게이트를 사용하지 않지만 각 단어가 다른 단어와의 관계 및 중요성을 제어하는 ‘attention score’를 동적으로 조정하여 게이트처럼 작동한다.
> 
> 따라서 **self-attention은 특정 정보가 더 강한 영향력을 갖도록 선택적으로 허용함으로써 게이트와 유사한 목적을 수행**한다.

- 초기 sigmoid, tanh 함수들은 입력 값이 매우 크거나 작을 때 기울기가 거의 0에 가까워지는 그래디언트 소실문제가 발생하여 학습이 느려지거나 멈출 수 있었다.
- Relu 함수는 입력이 양수일 때만 그래디언트가 흐리기 때문에 학습이 더 잘 되는 경향이 있다.
- 논문에서 제안하는 smooth하고 non-monotonic(비단조적)인 Swish 함수는 f(x) = x * sigmoid(x) 로 정의된다.

![](assets/Pasted%20image%2020250420183831.png)

- Non-monotonicity(비단조성) 특성은 함수가 항상 증가하거나 감소하지 않는다는 것을 의미한다. 즉, Swish 함수의 그래프는 입력값에 따라 증가했다가 다시 감소할 수 있다. 그리고 음수 값 출력 부분에서 양수 값 출력하는 영역으로 부드럽게 전환된다는 것을 뜻하기도 한다. 이와 같은 비단조적 특성은 Swish를 Relu와 같은 다른 활성화 함수들과 구별되게 한다.
- self-gating은 동일한 값을 게이트 자체에 사용하여 게이팅 메커니즘을 단순화한 것으로 입력 값이 다음 레이어에 얼마나 강하게 영향을 미칠지를 결정할 수 있다.
- Lstm에서 나온 아이디어로써, x와 $\sigma({\beta}x)$ 를 분리해놓고 생각하면 $\ \sigma({\beta}x)$는 시그모이드 함수로 0~1사이의 값을 갖는데, 그 값을 자기자신 x가 결정하기 때문에 self-gating이라고 부름. 이 또한 generalization을 돕고 overfitting을 막아줌

## Swish 의 속성
![](assets/Pasted%20image%2020250420185256.png)

- Swish의 Unboundedness(무한성) 통해 모델은 작은 그라데이션 업데이트로 인해 "고착"되는 것을 방지할 수 있으므로 복잡한 패턴을 더 쉽고 빠르게 배울 수 있습니다.
- Unbounded above for x ≥ 0 : x ≥ 구간에서 값의 상한이 없음. 모든 양수값을 허용함으로써 정보를 살려가겠다는 의미로, 입력의 양수값이 더 커질수록 선형 함수에 접근하게 된다. (선형 함수에 가까워진다는 것은 입력값이 매우 클경우 입력값 자체와 거의 동일해진다는 것을 의미)
- Bounded below x < 0 : x < 0 구간에서 값의 하한이 존재하며, 음수값에 대해 약간의 정보를 살려 Dying 문제를 해결한다. 큰 음수값에 대해서는 강한 regularization 효과가 있다.
- Differentiability(미분 가능성) & Smoothness(부드러움) : 모든 구간에서 도함수가 연속 함수이다. 기울기의 불연속 구간이 없기 때문에 oscillation(진동)이 적어 빠른 수렴이 가능하다.
- Computationally expensive : Sigmoid 함수(지수 함수)가 들어가기 때문에 계산이 다소 올래 걸린다.
![](assets/Pasted%20image%2020250420185326.png)
- 그림에서 Relu는 non-smooth 성질으로 무작위 신경망에서 수많은 날카로운 영역들이 존재한다.
- Swish 함수의 smoothness는 최적화와 일반화에 효율적인 역할을 하며, output landscape의 부드러움은 loss landscape의 직접적인 영향을 미친다. 직관적으로 원활한 loss landscape는 탐색이 더 용이하고 초기화 및 학습 속도에 대한 민감도가 줄어들기 때문에 최적화하기가 더 쉬울 가능성이 높다.

## Comparing Swish to ReLU
![](assets/Pasted%20image%2020250420185339.png)

- Swish는 최적화가 어려울 때 40~50개 레이어 범위에서 ReLU보다 큰 차이로 성능을 능가한다. 다시말해 매우 깊은 네트워크에서 Swish는 ReLU보다 더 높은 테스트 정확도를 달성할 수 있다는것이다.

![](assets/Pasted%20image%2020250420185400.png)
- 다양한 배치 크기로 테스트 했을 때도 Swish가 ReLU보다 훨씬 뛰어난 성능을 발휘한다.
