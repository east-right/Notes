 ## Attention

Attention(이하 어텐션)은  말 그대로 '집중'이다. 모든 말 혹은 문장에는 가장 큰 목적이 되는 단어가 존재하고 그 단어 의미를 중심으로 문장이 이루어 진다. LM도 문장을 생성 혹은 이해를 할 때 그 각 단어의 중심을 알아채면 조금더 좋은 성능을 보장하지 않을까? 그런 의미의 어텐션 기법이다.

기존의 Seq2Seq 모델은 RNN 기반 모델들은 고질적인 문제가 하나 존재한다. 그 문제점이 문장의 길이가 길어지면 점점 그 앞의 단어의 정보는 흐릿해진다 점이다. 이러한 문제는 시간의 순서대로 입력을 받아 각 정보를 문장의 길이 만큼 뒤로 넘기는 작업의 문제점이었다. 

이러한 문제를 해결하기 위해 BI-LSTM과 같은 양방향 모델도 등장을 하면서 해소가되는듯 했지만 양방향 모델은 결구  NLG에 해당하는 문장 생성에는 사용하지 못한다는 점과 Seq2Seq는 인코더의 정보를 디코더로 넘길 때 Context Vector를 만들어 넘긴다는 작업 때문에 필연적으로 온전한 정보를 넘기지 못하는 문제가 발생하였다.

![image-20240901133414619](assets/image-20240901133414619.png)

Seq2Seq는 위 의 사진과 같이 정보를 압축하는 Context Vector를 만드는 과정에서 필연적으로 정보의 손실 Bottleneck이 발생한다. RNN 계열 모델의 문제점인 장기 의존성 문제와 더불어 이는 언어모델 개선에 항상 에러가 되는 사항이었다.

이러한 문제를 개선하기 위해 등장한것이 Attention이다.

>   - 콘캣 어텐션(Concat Attention): 
>2. 루옹 어텐션

>3. 스케일드 닷 프로덕트 어텐션

### Dotproduct Attention

![image-20240901140939043](assets/image-20240901140939043.png)

가장 이해하기 쉬운 어텐션 방법인 닷프로덕드 어텐션이다. 버나다우어텐션 등등 있지만 이 닷프로덕트가 맨 처음 이해하기는 제일 쉽다.

어텐션은 아래와 같은 방식으로 작동한다.

1. 각각 쿼디(Query, Q), 키(Key, K), 밸류(Value, V)에 대한 값을 구한다.
   - 여기서 K와 V는 애지간한 상황이 아니면 같은 값을 가진다.
2. Q와 K의 유사도를 구한다.
3. 이 유사도를 바탕으로 나온 값을 V에 적용시킨다.
4. 이러한 값을 어텐션 스코어라고 말한다.

여기서 저 유사도는 내적 혹은 코사인 등등 여러가지가 있지만 여기 닷프로덕트어텐션에서 내적을 활용하여 Q와K의 유사도를 구한다.

![image-20240901144633738](assets/image-20240901144633738.png)

닷 프로덕트 어텐션은 위와 같은 방시으로 진행된다. 먼저 디코더 부분의 예측하고자 하는 시점 t의 은닉상태를 구한다. 이 디코더의 은닉상태와 인코더의 모든 시점 은닉 상태와 유사도를 구한다. 닷 프로덕트는 내적을 활용하여 유사도를 구한다.

디코더의 t시점의 은닉 상태는 Q로 취급하고 인코더의 각 시점의 은닉 상태는 K로 취급한다. 식은 𝑠𝑐𝑜𝑟𝑒(𝑠𝑡 , ℎ𝑖 ) = 𝑠𝑇 𝑡 ℎ𝑖이고 각각의 은닉 상태를 곱하여(내적 연산)을 통해서 나온값을 **어텐션 스코어 벡터**라고 한다. 이 어텐션 스코어 벡터를 전부 Softmax를 덮어씌워 각 스코어의 값이 총합이 1인 0과 1사이의 값으로 변하게 만든다. 

![image-20240901144951244](assets/image-20240901144951244.png)

![image-20240901145020966](assets/image-20240901145020966.png)

소프트 맥스를 씌운 값을 어텐션 스코어 분포라고 하고 어텐션 스코어 분포의 값을 기존의 인코딩 은닉층의 값에 곱한다. 이 어텐션 스코어 분포는 QK의 내적을 0과1사이의 값으로 변형한 값이기에 각 은닉층에 곱해지면 내적값이 높은 즉 벡터가 서로 비슷하거나 유사하면 인코딩 은닉층의 값을 유지하고, 유사하지 않으면 인코딩 은닉층의 값을 최대한 삭제시킨다.

이렇게 나온 벡터의 값을 전부 더한다. 인코딩의 은닉층의 값이 softmax로 인해 값이 변한걸 전부 합쳐 최종적으로 어텐션 밸류를 구합니다.

$𝑎𝑡 = 𝑠𝑢𝑚𝑁 𝑖=1𝛼 𝑡 𝑖ℎ𝑖$

어텐션 밸류를 구하는 수식이다. 이러한 어텐션 밸류는 종종 인코더의 문맥을 포함하고 있다고 하여 **컨텍스트 벡터(Context Vector)**라고 불린다.

> Seq2Seq + Attention 모델은 기본적으로 은닉층의 값은 각 단어의 값이라고 보면 편하다. LSTM모델은 각 시점의 단어마다 하나씩 임베딩 시켜서 모델에 넣기에 이렇게 인코딩 모델의 은닉층의 값은 그 t시점의 단어에 대한 값이라고 생각하면 된다. 
>
> 즉 디코딩 모델이 이번 시점에서 중점으로 봐야하는 단어의 정보만 최대한 남겨서 단어예측에 사용한다. 그래서 유사도를 사용해서 이번 시점에서 최대한 봐야하는 위치 혹은 단어를 찾는것이다.

```
#아래는 대충 내가 계산한 닷프로덕드 어텐션 밸류까지의 구현 코드이다.
import numpy as np

# Given vectors
a = np.array([2.341, 5.23123, 1.2333, 4.12455678])
b = np.array([1.341, 4.23123, 1.2333, 6.12455678])
c = np.array([4.341, 5.23123, 3.2333, 2.12455678])
d = np.array([1.341, 9.23123, 1.2333, 4.12455678])
Q = np.array([1.341, 2.23123, 3.2333, 4.12455678])

# Step 1: Compute the dot product (Attention scores) between Q and each of a, b, c, d
dot_product_a = np.dot(Q, a)
dot_product_b = np.dot(Q, b)
dot_product_c = np.dot(Q, c)
dot_product_d = np.dot(Q, d)

attention_scores = np.array([dot_product_a, dot_product_b, dot_product_c, dot_product_d])

# Step 2: Apply softmax to the attention scores
def softmax(x):
    exp_x = np.exp(x - np.max(x))  # subtract max for numerical stability
    return exp_x / exp_x.sum()

attention_weights = softmax(attention_scores)

# Step 3: Calculate the weighted sum of the value vectors (a, b, c, d) using attention weights
value_vectors = np.array([a, b, c, d])
attention_output = np.sum(attention_weights[:, np.newaxis] * value_vectors, axis=0)

attention_scores, attention_weights, attention_output
```

이제 컨텍스트 벡터를 **디코딩의 은닉층의 값 즉 Q에 concatunate한다.**(이건 더하는게 아니라 그냥 연결하는거다.) 이 concatunate한 값을 vt라고 하고 이 vt 벡터는 현재 시점의 예측단어인 yt를 예측하는데 사용하게 된다. 이제 기본적인 신경망 방식의 하이퍼볼릭탄젠트를 사용하는 은닉층에 계산되어 최종적으로 나온 값을 사용하여 출력층 소프트맥스 층에 보내어(𝒚𝒕 = softmax(𝑾𝒚𝒔 𝒕+𝑏𝑦)) 이번 시점의 디코딩이 예상한 단어를 출력한다.

### 바다나우 어텐션

바다나우 어텐션은 닷 프로덕트 어텐션 보다 일찍 제안되었지만 보다 어렵다. 바다나우 어텐션은 컨텍스트 벡터화로 인한 보틀넥 현상을 줄이기 위해 제안된 방식이다. 

![image-20240901163411221](assets/image-20240901163411221.png)

버다나우 어텐션은 닷 프로덕트 어텐션과 다르게 t-1 시점의 디코딩 은닉층 값을 사용하여 어텐션 시점을 구한다.

또한 **그 서로의 은닉층의 값을 바로 사용하지 않고 아래와 같이 학습 가능한 w를 생성하여 그 값을 변환 시킨 다음 두 값의 결과를 더하는 방식으로 어텐션 스코아를 구한다.**

![image-20240901163847716](assets/image-20240901163847716.png)

위와 같은 방식으로 각 은닉층에 학습 가능한 w를 곱하고 그 값을 더한 다음 활성화 함수인 tanh을 사용하여 그 값을 또 학습 가능한 새로운 w를 또 들고와서 다시 곱하여 어텐션 스코어를 구한다.

![image-20240902210832957](assets/image-20240902210832957.png)

어텐션 분포는 위의 닷 프로덕트 어텐션이랑 동일하게 Softmax를 사용하여 구하고 인코더의 은닉층의 값에 곱하여 집중해야하는 포인트인 컨텍스트벡터를 구한다. 

![image-20240902211008502](assets/image-20240902211008502.png)

이후 바다나우 어텐션은 이렇게 나온 **컨텍스트 벡터를 디코더의 모델에 들어가기 전의 예측해야하는 시점의 단어의 임베딩 벡터에 Concatunate를 하여 RNN 모델에 넣어 이번시점의 예측 단어를 받는다.**

![image-20240902211438623](assets/image-20240902211438623.png)

**여기서 바다나우 어텐션과 루옹 어텐션(닷 프로덕트 어텐션 류)의 가장 큰 차이점이 존재하는데 바다나우 어텐션은 어텐션 밸류를 구할 때 이전 시점(t-1)의 디코딩 은닉층 값을 사용하기에 컨텐스트 벡터를 구하고 이번시점(t)의 값과 Concatunate를 할 때는 디코더 모델에 들어가기전에 진행한다. **

**그에 반해 닷 프로덕트 어텐션은 이번 시점의 디코딩 은닉층의 값을 사용하여 컨텍스트 벡터를 출력하기에 Concatunate를 디코더의 은닉층에서 나온 값과 합쳐서 그 값을 출력층에 보내어 결과를 받는다. 위의 그림이 매우 큰 차이점이다.**

## Transformer

어텐션의 등장으로 LM은 아무리 긴 문장도 정보 손실에 상관없이 집중할 곳 을 찾아 보다 좋은 결과를 반환했다. 하지만 아직 문제가 존재하는데 RNN 기반 모델의 공통적인 문제은 순차적인 작업으로 인한 긴 작업시간은 개선이 되지 않았다. 오히려 Attention 작업을 추가로 해야했기에 학습량이 배는 늘어나 시간이 더욱 올래 걸리기 시작했다. 그리고 또한 개선이 되었다고 해도 긴문장에 대한 정보 손실은 여전한 문잿거리였다.

**트렌스포머 모델은 이러한 배경에서 어텐션 만으로 모델을 구성할 순 없을까? 라는 생각에서 시작하였다.** 막말로 CV에 강점을 가지는 CNN도 1D-CNN으로 자연어 모델에 꽤나 강력하게 적용이 가능했는데? 이러한 생각으로 RNN 계열 모델은 지워버리고 오직 어텐션 모델 결과만 출력 받아 그냥 DNN 돌리면 되는거 아닌가? 라는 생각은 대박을 쳤다.

![image-20240902213804760](assets/image-20240902213804760.png)

최초의 트렌스포머 모델은 기계번역 모델을 구현하기 위해 학습되고 연구되었다. 기존의 Seq2Seq + Attention의 인코더-디코더 구조는 여전히 유지하지만 RNN 계열 학습 방식을 버리고 따로 Attention 층을 만들어 어텐션 값을 구하고 그 값을 FFNN에 넣는 방식으로 모델을 구현하였다. 이 방식의 가장 큰 장점은 역시 RNN 방식을 사용하지 않음으로써 병렬연산이 가능하므로 모델의 속도가 매우 빨라졌다.

![image-20240902214836339](assets/image-20240902214836339.png)

트렌스포머 모델은 기본적으로 다수의 인코더와 다수의 디코더를 사용한다. 논문의 경우 6개를 사용하여 사진에도 예시를 6개 든다.

기존의 Seq2Seq랑 전체적인 인코더 디코더 흐름은 비슷한데 다른점이 존재한다. 기존의 Seq2Seq는 RNN 계열 모델을 사용하여 인풋을 병렬적으로 받을수 없었다. 하지만 트렌스포머 모델은 **Positional Encoding**을 사용하여 단어의 위치 정보를 기록하고 모델에 Input 값을 주기에 병렬적인 작업 처리가 가능해 졌다.

![image-20240902220124891](assets/image-20240902220124891.png)

포지셔널 인코딩은 그렇게 어렵지 않다. 각 포지션에 해당하는 벡터를 만들어 임베딩 벡터를 거치고 튀어나온 값에 더해주면서 그 단어의 위치 정보를 추가시키는 방식으로 진행합니다. 포지셔널 인코딩 행렬을 만드는 방법은 아래와 같다.
$$
PE(pos,2i)=sin(pos/10000^{2i/d_{model}})
,,
PE(pos,2i+1)=cos(pos/10000^{2i/d_{model}})
$$
위의 수식은 포지셔널 인코딩 행렬을 만드는 수식이다. i가 짝수는 사인함수를 사용하고 홀수는 코사인 함수를 사용하여 위치에 따른 정보를 각자 더한다. 여기서 pos는 입력 문장의 임베딩 벡터의 위치이고 i는 임베딩 벡터의 차원 dmodel은 트랜스포머의 입,출력 자원 같은 말로 임베딩 벡터의 차원의 크기이다.

![image-20240902222427322](assets/image-20240902222427322.png)

여기서 헷갈리면 안되는게 pos나 i나 뭐 어떠한 값이 아니라 그냥 위도 경도와 같은 좌표를 의미한다. pos는 이 단어가 몇 번째 단어인지 의미하고 i는 임베딩 벡터의 크기 중 여기가 어디인지 나타낸다. 옆의 그림은 문장의 길이 만치 임베딩 벡터를 값으로 나타낸걸 그래프로 나타냈을 때이다. 그림을 보면 단어의 길이가 길수록 임베딩 벡터의 차원을 크게 해야 포지셔널 인코딩 행렬의 값이 다양해지는걸 확인 가능하다.

추후 다른 모델에선 포지션 인코딩을 다른 수식을 사용하여 구현하기도 하고 수식으로 구현하지 않고 아예 파라미터를 준 다음 학습을 시키는 방식으로도 진행한다.

>원핫 인코딩을 활용한 위치 기록은 전체의 순서 위치에 대해서 독자적인 유일한 값을 주기는 편하지만, 말 그대로 yes or no를 활용한 기록으로 유일성을 기록하기 위한 목적만을 들고있어 상호 순서간의 상관성을 기록하긴 힘들다. 이 말에 대해서 생각을 해봤는데 상호 순서가 중요한 이유가 우리의 목표는 언어에 관한 문제이기에 bi-lstm을 사용하는 목적과 비슷하게 양옆의 정보를 기준으로 우린 이번 단어를 유추한다. 하지만 원핫 인코딩은 양옆의 상관성에 대한 정보를 기록하게 하는데는 무리가 조금 있다.
>
>**Sin 함수**
>
>사인 함수는 값이 변해도 그 정보가 급변하지 않아 상호간의 관계를 부드럽게 연결이 가능하다. 근데 사인 함수는 계속 반복하다 보면 서로 다른 위치인데도 동일한 Sin(x)을 가질 수도 있는데 이는 또 다른 Sin함수와 조합하면 구별이 가능하다. 이 때문에 Sin 함수와 비슷한 Cos를 들고와 조합하여 상호간의 관계가 이루어지는 인코딩을 완성시킨다.
>
>코사인 함수는 SIn을 옆으로 이동시킨 값이기에 각각의 함수는 하나의 위치에 대해서 정보를가지고 그걸 조합하여 수열을 만든다.

여기 attention은 맨 처음 배운 attention 방식이랑 같다. Self Attention 방식이 아니기에 QKV 가 모두 같지 않고 Q는 Decoder의 벡터를 기준으로 하고 K,V는 Encoder 층의 결과 값을 기준으로 한다. 

![image-20240908162955181](assets/image-20240908162955181.png)

즉 인코더의 값과 디코더의 값을 사용하여 어텐션을 진행하되 그걸 Multy head로 한다는게 차이점일 뿐이다.
