# Abstract
- 포지션 인코딩은 트랜스포머 구조에서 의존성(dependency)을 학습하는 데 중요한 정보를 제공한다.
- 본 논문에선 PoPE하는 임베딩 단어에 대한 위치 정보를 제시하는 독특한 방법을 제시한다.
- RoPE는 다음과 같은 유용한 특성을 제공한다.
	- 시퀀스 길이에 대한 유연성
	- 상대 위치 간 거리가 멀어질수록 토큰 간의 의존성이 점진적으로 감소하게 만듬
	- linear self-attention 구조에서도 상대 위치 인코딩 사용이 가능하게 확장
- RoPE 는 rotation 행렬을 이용하여 절대 위치를 인코딩하고, self-attention 식에서 relative position dependency (_상대 위치 의존성_) 정보를 더해준다.

## 1. Introduce
- 기존 연구들 에선 **사전 정의된 수학 함수**를 통해 생성된 **절대 위치 인코딩** 을 문맥 표현에 더하는 방식이 있고,  **학습 가능한 절대 위치 인코딩**  또한 널리 사용되고 있습니다.
- 상대 위치 인코딩(relative position encoding)에 주목하여,  상대적인 위치 정보를 주의 메커니즘 내에 직접 통합하는 방법을 제안
- 또한 Neural ODE 관점에서 위치 인코딩의 주위 단어 의존성을 **복소수 공간에서 위치 정보를 모델링**하는 방법 제시
- **하지만 이들 모두 위지정보와 임베딩 메트릭스가 덧셈 방식으로 결합하기에 적합하지 않음**
> 복소수 공간에서 정보를 모델링한다는 의미
> - 복소수는 `a+bi`와 같이 실수부 + 허수부로 구성
> - 복소수는 우리가 흔히 아는 실수 평면(xy로 이루어진 4분계수 평면)으로 표현하는데 그치지 않고 phase(방향)과 크기를 나타내는 원형을 실수 평면에 더해서 나타냄 이를 복소수 평면이라고 함
> - 이 복소수 평면에선 위치정보를 위상으로 또는 주파수의 형태로 표현가능
> - **즉 위치마다 다른 복소수 위상을 임베딩에게 부여해서 위치 정보를 벡터의 방향성 혹은 주파수와 같은 주기성으로 나타낸다는 의미**
> - 이 방식은 푸리에 변환의 원리와 유사하게 작동하여 **긴 거리간의 토크 관계를 더 부드럽게 표현할 수 있게 해준다.**
