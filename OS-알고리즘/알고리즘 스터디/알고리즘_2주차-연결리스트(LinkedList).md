# 어레이(array)
- 어레이(=리스트)는 자료구조에서 가장 기본적인 형태
- 보통 리스트(List)라고 부르지만 파이썬에선 어레이(array)라고도 불린다.
- 주로 대괄호`[]`에 value 들이 들어간다.
- 파이썬으로 어레이(리스트)를 만드는 방법은 아래와 같다.
	- List(1,2,3)
	- `[1,2,3]`
	- numpy.array(1,2,3)

# 연결리스트(LinkedList)
![](assets/Pasted%20image%2020250302172826.png)
- 연결리스트란 어레이랑 다르게 Index(주소)가 존재하지 않는다.
- 위 그림과 같이 연결리스트는 각자의 공간에 하나의 값과 다음 값이 뭔지 적혀있다.
- 그래서 Index가 없기에 값의 순서 혹은 순위를 한번에 알아볼 수 없다.
- 파이썬에선 LinkedList를 구현해주는 함수가 없어서 직접 구현해야 한다.
- 연결리스트에선 그래서 하나의 값과 다음 값의 위치정보를 들고 있는 자료를 **노드(Node)** 라고 한다.

# 연결리스트를 사용하는 이유
- 어레이와 연결리스트 모두 데이터를 저장하는 가장 대표적인 자료구조이다.
- 하지만 가장 큰 차이첨이 존재하는데 **Index의 존재 유무**이다.
- 자료구조에서 가장 중요한 작업은 3가지로 추출(접근), insert, delete 이다.
	- 어레이: 파이썬의 대표적 list, 접근이 쉬움, insert 어려움
	- 연결리스트: 파이썬에선 직접 구현, 접근 어려움, insert 쉬움
- 어레이는 특정값에 접근하기 위해 Index라는 주소가 있어 Index를 통해 검색을 하면 손쉽게 접근이 가능하다.
- 하지만 새로운 값을 넣을 때는 이 Index가 발목을 잡는데 Insert를 할 땐 넣는 위치를 기준으로 그 뒤의 모든 값을 한 칸씩 뒤로 밀어야 한다. 그런 다음 값을 넣는다.
- 연결리스트는  Index라는 주소가 없어 접근을 할려면 시작 노드에서 부터 원하는 값이 나올 때까지 계속 탐색을 해야한다.
- 하지만 새로운 값을 넣거나 뺄 때는 원하는 노드의 다음 값의 위치정보들만 수정하면 되기에 어레이보다 속도가 빠르다.
## Array vs Linked

| 상황        | Array                                           | LinkedList                              |
| --------- | ----------------------------------------------- | --------------------------------------- |
| 특정 원소 조회  | O(1)                                            | O(N)                                    |
| 중간에 삽입 삭제 | O(N)                                            | O(1)                                    |
| 데이터 추가    | 데이터 추가 시 모든 공간이 다 차 버렸다면 새로운 메모리 공간을 할당 받아야 한다. | 모든 공간이 다 찾어도 맨 뒤 의 노드만 동적으로 추가하면 된다.    |
| 정리        | 데이터에 접근하는 경우가 빈번하면 Array를 사용하자                  | 삽이과 삭제가 빈번하다면 LinkedList를 사용하는 것이 더 좋다. |
