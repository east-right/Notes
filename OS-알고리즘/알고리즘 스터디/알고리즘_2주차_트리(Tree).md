## 트리(Tree)
- 앞에서 공부한 큐와 스택은 자료구조에서 선형 구조라고 한다.
- 선형 구조란 자료를 구성하고 있는 데이터들이 순차적으로 나열 시킨 형태를 의미한다.
- 이번에 공부할 트리는 **비선형 구조의 자료구조**이다.
- 비선형 구조는 선형 구조와는 다르게 데이터가 계층적 혹은 망으로 구성되어있다.
- 선형구조와 비선형 구조의 차이점은 형태뿐만 아니라 용도에서도 차이점이 있다.
	- 선형구조는 **자료를 저장하고 꺼내는 것**에 초점이 맞춰져 있다.
	- 비선형 구조는 표현에 데이터 구성에 대한 **표현에 초점**이 맞춰져 있다.
![](assets/Pasted%20image%2020250309124221.png)
- 대표적인 트리 형태의 자료구조인 폴더를 활용한 파일 저장 구조이다.
- 트리는 나중에 배울 **[그래프(Graph)]()형식의 자료구조중 하나이다.**
- 하나의 루트 노드의 하위 트리로 구성되어 있다.
- 단순 순환하는 형식을 가지지 않게 연결된 무방향 그래프 구조이다.
- 하위 노드(자식 노드)는 복수개의 상위 노드(부모 노드)를 가질 수 없다.
![](assets/Pasted%20image%2020250309130433.png)
- 트리의 특징을 더욱 활용하기 위해선 그래프를 알아야 하는데 본 글에선 거기까지 다루지 않는다.
## 트리의 용어
![](assets/Pasted%20image%2020250309125149.png)
- Node
	- 트리에서 데이터를 저장하는 기본 요소
- Root Node
	- 트리의 제일 최상단에 위치하는 노드
- Level
	- 최상위 노드를 Level0 으로 하였을 때, 하위 Branch로 연결된 노드의 깊이를 나타냄
- Parent Node
	- 어떤 노드의 상위 레벨에 연결된 노드(즉 내가 말하는하는 노드의 바로 위에 있는 Node)
- Child Node
	- 어떤 노드의 하위 레벨에 연결된 노드(즉 내가 말하는 노드의 바로 아래에 있는 Node)
- Sibling
	- 동일한 Parent Node를 가진 노드(즉 내가 말하는 노드의 위에 있는 Node의 하위에 연결되 또 다른 Node)
- Leaf Node(external node, outer node)
	- Child Node를 가지고 있지 않은 노드
- Branch Node(internal node, inner node)
	- Child Node를 가지고 있는 노드
- Depth
	- 트리에서 Node가 가질 수 있는 최대 level
## 트리의 종류
### 편향트리
- 모든 노드들이 자식을 하나만 가진 트리
- 왼쪽 방향으로 자식을 하나씩만 가질 때 left skew tree, 오른쪽 방향으로 하나씩만 가질 때 right skew tree라고 함.
### 이진트리
- 트리에서 가장 기본이 되고 다른 비선형 자료구조와 다른 특징을 가진 트리 형태
- 이진 트리의 가장 큰 특징은 **모든 각 노드가 최대 두 개의 자식 노드를 가지는 트리 형태**를 말한다.
- 하위의 노드가 3~5개 일 수 없고 무조건 0,1,2개만 가질 수 있다.
- 모든 노드들이 자식노드를 2개 들고 있으면 이걸 '포화이진트리'라고 한다.
```python
  0   level 0
 0 0  level 1
0 0 0 level 2 # 이진트리(o), 포화이진트리(o)

  0   level 0
 0 0  level 1
0 0   level 2 # 이진트리(o), 포화이진트리(x)

   0    level 0
 0 0 0  level 1
0 0 0 0 level 2 # 이진트리(x)
```
### 완전 이진 트리
- **이진트리에서 가장 중요한 트리 모형이다.**
- 완전 이진트리는 이진트리에서 자식 노드를 삽입하는 방식에서 차이가 난다.
- 완전 이진트리의 성립 조건은 **노드를 삽일할 때 최하단 왼쪽 노드부터 차례대로 삽입해야 한다.**
- 포화 이진트리 일 필요는 없다. 하지만 무조건 모든 데이터는 왼쪽 노드부터 채워져 있어야 한다.
![](assets/Pasted%20image%2020250309132004.png)
- 위와 같은 트리형식을 지키는 완전 이진트리의 가장 큰 특징은 **다른 Node형 자료구조랑 다르게 배열(Lisr or Array)로 간편하게 나타낼 수 있다.** 이다.

**완전 이진트리 특징**
- 물론 node를 써서 정석적으로 구현이 가능하지만, 트리 자료구조에서 모든 데이터가 왼쪽부터 채워진다는 조건을 지키면 아래과 같이 표현이 가능하다.
```python
트리를 배열(List)로 구현할 때는 편의성을 위해 0번째 인덱스는 사용되지 않는다.
그래서 None 값을 배열에 넣고 시작합니다! [None]

      8      Level 0 -> [None, 8] 첫번째 레벨의 8을 넣고,
    6   3    Level 1 -> [None, 8, 6, 3] 다음 레벨인 6, 3을 넣고
   4 2 5     Level 2 -> [None, 8, 6, 3, 4, 2, 5] 다음 레벨인 4, 2, 5를 넣으면 된다.
```
- 최종적으로 이진트리가 `[None, 8, 6, 3, 4, 2, 5]`이라는 배열로 표현이 된다.
- 이렇게 표현된 배열로 트리 구조를 분석해보면 아래와 같이 파악이 가능하다.
	1. 현재 인덱스 * 2 -> 자신의 왼쪽 자식 노드의 인덱스
	2. 현재 인덱스 * 2 +1 -> 자신의 오른쪽 자식 노드의 인덱스
	3. 현재 인덱스 // 2 -> 자신의 부모 노드의 인덱스(본인 인덱스에서 나누기 2를 한 몫)
- 예를 들어 index 1인 8의 왼쪽 자식은 6, 오른쪽 자식은 3이다.
- 그러면 `1*2 = 2` 그래서 index 2에 6이 들어 간다.
- and `1*2+1 = 3` 그래서  index 3에 3이 들어간다.
- index3의 부모를 찾아가면 `3 // 2 = 1`이기에 index 1이 부모란 걸 알 수 있다.
- 이를 다시 생각해보면 `[None, 8, 6, 3, 4, 2, 5]` 는 8 밑에 6, 3 이 있고, 6, 3 밑에 4, 2, 5가 있는 완전 이진 트리구나! 생각할 수 있다.

**완전 이진트리의 탐색 시간**
- 완전 이진트리의 탐색 시간은 **트리의 높이를 활용한다.**
- 트리의 높이란, 루트 노드부터 가장 아래의 리프 노드까지의 길이를 말한다.
```python
      o      Level 0  # 루트 노드
    o   o    Level 1
   o o o     Level 2  # 가장 아래 리프 노드

이 트리의 높이는 ? 2 - 0 = 2! 
```
- 트리의 높이는 위와 같이 나타낼 수 있다.
- 만약 levle1 에서 가장 아래까지의 높이를 구하는건 `2-1 = 1`로 나타낼 수 있다.
- **탐색시간은 여기서 포화 이진트리라 가정하고 트리의 모든 노드의 개수가 몇 개 인지가 중요하다.**
- 깊이 즉 Level이 k라고 하면 각 Level에 들어갈 수 있는 노드의 개수는 $2^k$ 개 이다.
```python
      1            Level 0 -> 1개
    2   3          Level 1 -> 2개 
   4 5 6 7         Level 2 -> 4개
 8 9....... 14 15  Level 3 -> 8개 
                   Level k -> 2^k 개
```
- 이게 포화 이진트리이면 아래와 같이 나타난다.
$$
1 + 2^1 + 2^2 + 2^3 + 2^4 ..... 2^h
$$
- 즉, 이를 수식으로 표현하면 $2^{(h+1)} - 1$로 표현이 가능하다.
- 최대 노드의 개수가 N일 때 높이를 나타내는 h는 과연 얼마일까
$$
2^{(h+1)} -1 = N \rightarrow h=log_2 (N+1) -1
$$
- 지수로그를 활용하여 위와 같은 수식으로 나타낼 수 있다.
- 즉 이진 트리 노드의 개수가 N일 때 최대 높이가 $h=log_2 (N+1) -1$이므로 이진트리의 높이는 **$O(log(N))$** 이라고 알 수 있다.

## 이진 탐색 트리(Binary Search Tree, BST)
![](assets/Pasted%20image%2020250309152700.png)

- 이진 탐색트리는 순서화된 이진트리로 아래와 같은 규칙을 따른다.
	- 모든 부모 노드는 왼쪽 자식 노드보다 큰 값을 가져야 한다.
	- 모든 부모 노드는 오른쪽 자식 노드보다 작은 값을 가져야 한다.
- 트리위 순회 구조중 하나인 중위순회를 적용하여 리스트를 만들면 오름차순 정렬이 된다.
	>중위 순회: 가장 왼쪽 하위 트리를 방문하여 모든 트리를 방문하고 루트를 확인 후 오른쪽 하위 트리의 왼쪽부터 다시 확인한다. 그냥 간단하게 그림상 가장 왼쪽에 존재하는 순서대로 탐색한다.
	- 위 그림은 `[1,3,4,6,7,8,10,13,14]`
