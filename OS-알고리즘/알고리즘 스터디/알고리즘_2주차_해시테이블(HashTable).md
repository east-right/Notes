#알고리즘 #자료구조
![](assets/Pasted%20image%2020250308142636.png)
- 해시테이블은 컴퓨터 자료구조에서 제일 중요한 자료구조이다.
- 해시테이블이란 **해시 함수(hashFunction)라 불리우는 함수를 사용하여 키를 넣으면 index를 발급받아 그 index에 value를 매핑하는 자료구조이다.** 키를 값에 매핑하는 자료구조가 된다.
- Python의 딕셔너리 자료형을 생각하면 편하다. 
- 내가 과거에 ANN 공부할 때 간단하게 공부했던 기억이 있다.(여기에 링크 넣기)
- 해시테이블은 컴퓨터가 정보를 저장할 때 사용하는 방식으로 추천 알고리즘과 같은 노드 서치에 특화된 알고리즘에 많이 쓰이는 자료구조이다.

**해시테이블 용어**
- 해싱(Hash)
	- Key(사진에서 데이터)와 매칭되는 값을 검색하는 과정, 자료구조 내에서의 검색을 목적으로 한다.
- 해시(Hashing)
	- 해시함수를 통해 나온 값을 의미하며, 버킷(bucket)이라 불리는 저장소에 담긴다.
- 슬롯(Slot)
	- 해시 충돌 발생시를 대비해 이미 다른 Key에 대한 Value 값이 들어있는 bucket에 같은 hash값을 가진 다른 Key의 Value값이 들어가게 되는 장소, LinkedList를 통해 다음 값을 연결 시킨다.
- 로드 팩터(Load Factor)
	- 해시테이블에 원소가 차있는 비율
	- 해시테이블의 충돌을 줄여 성능을 높이기 위해 중요한 요소이다.
	- 정체 테이블 내 Bucket 공간 수를 원소의 개수에 나눈 값이다.
	- $Load Factor=\frac{'원소의 개수'}{'전체 공간수'}$
	- 로드 팩터 비율에 따라 해시함수, 테이블 크기 조정 여부를 결정한다.
	- 제대로 된 동작을 위해선 이 적재율이 1이 넘지 않도록 유지한다.
## 헤시 함수(Hash Function)
- 헤시함수란 임의의 크기 데이터를 고정 크기 값으로 매핑하는데 사용할 수 있는 함수를 의미한다.
- 말이 좀 어려운데 쉽게 말해서 값이 들어오면 로직을 타고 나오는 결과값이 미리 정의해 놓은 값들 중에서 나오게 만드는 함수를 의미한다.
- 강의에서 대표적으로 예시를 들기를 '특정 값이 들어오면 무조건 나머지를 반환하는 함수'가 좋은 해시 함수의 예라고 한다.
	- 헤시 함수가  `int %%3` 3 이면 나머지는 0, 1, 2 만 나오는 데, 이와 같이 해시함수는 값이 들어와도 미리 정의해놓은 결과값들의 범위중 하나에 속하게 된다.

## 충돌과 해시테이블 종류
![](assets/Pasted%20image%2020250308145215.png)
- 아무리 좋은 헤시 함수라도 충돌을 피하기는 어렵다.
- 기본적으로 들어오는 input data들의 범위는 정해져 있지 않은데 해시함수로 나오는 출력값의 범위는 정해져 있기 때문이다.
- 입력값이 달라고 똑같은 결과가 나오면 이를 **충돌**이라고 한다.
- 이를 다루는 방식은 대표적으로 두 가지가 있는데 체이닝(Chaining)과 오픈 어드레싱(Open Addresing) 이다.
- 체이닝은 충돌시 값을 '연결'을 시키면서 해결하고, 오픈 어드레싱은 probing를 통해 '빈 공간을 찾아' 값을 삽입하는 방식이다.
### 오픈 어드레싱(Open Addressing)
![](assets/Pasted%20image%2020250308150234.png)
 - 오픈 어드레싱은 충돌이 나면 뒤에 들어온 값은 **충돌이난 지점을 기준으로 주위를 탐색하여 빈공간(Bucket)에 값을 집어넣는 방식을 의미한다.**
 - 오픈 어드레싱에는 일반적으로 두 가지 문제점이 존재한다.
	 - 값들이 테이블에 골고루 퍼지지 않고 해시 함수의 특징에 의해 클러스터링 문제가 발생할 수 있다.
		 - 기본적으로 해시 함수를 통해 정의한 패턴을 통해 데이터 작업의 연산 횟수를 낮출 수 있는데 만약 데이터가 몰려서 클러스터가 발생하면 자연스럽게 해시테이블의 강점이 사라진다.
	- 기본적으로 빈 공간(빈 Bucket)을 탐색해고 거기에 값을 집어 넣기에 빈 공간을 항상 남겨둬야한다. 로드 팩터의 관리가 중요하다. 
 - 오픈 어드레싱의 탐사 방법은 두 가지가 있다.
	 - 선형 탐색(Linear probing)
		 - 충돌이 발생한 곳에서 다음 버킷이 비어있는 곳이 나올 때 까지 계속해서 조사하는 방법 이다.
		 - 테이블의 끝에 도달하게 되면 다시 테이블의 처음으로 간다.
	- 이차 탐색(Quadratic probing)
		- 선형탐사에서 발생하는 군집화(클러스터링)의 문제를 일정부분 해결하기 위해 고안된 방법
		- 충돌 전용 해시함수를 하나 더 만들어서 선형 탐색을 진행한 후 충돌이 일어나면 해당 함수를 사용하여 충돌을 피한다. 
		- 이렇게 하면 값이 뭉치지 않는다.
## 체이닝(Chaining)
![](assets/Pasted%20image%2020250308154312.png)
- 체이닝은 **충돌이 일어나면 Slot이라는 LinkedList를 활용하여 같은 해시값이 여러가지 값을 저장하는 방식을 말한다.**
- 체이닝은 오픈 어드레싱과 다르게 충돌을 대비하여 테이블의 크기를 늘려 bucket의 공간을 미리 확보할 필요가 없어서 **상대적으로 메모리소모가 적다.**
- 하지만 체이칭은 단점도 명확한데 아래와 같다.
	- 하나의 bucket에 slot이 쌓이면 쌓일수록 역으로 **시간 복잡도가 증가한다.**
	- Slot으로 인해 해시테이블 메모리 뿐만 아니라 추가적인 외부 메모리까지 사용한다. 그래서 **메모리 오버헤드가 날 위험이 높다.**
-  C++, JAVA는 체이닝을 택하고, Python, Ruby는 오픈 어드레싱으로 데이터 정보를 관리한다.
