- 지식 그래프(Knowledge Graph)의 개념은 다음과 같다.
	- 수학적으로 노드와 엣지를 기반으로 구성된 그래프이다.
	- 그래프의 각 노드는 현실 세계의 **실체(entities)** 를 나타내며, 엣지는 그들 간의 다양한 **관계(relationships)** 를 의미
	- 복잡한 데이터를 서로 연결하여 체계적으로 구성하는 강력한 방법
	- 주로 조직적이고 협업적인 환경에서 귀중한 지식을 캡처하고 저장하는 데 주된 목적
	- 사람이 데이터를 이해하기 쉽게 만들 뿐만 아니라, 최근에는 **LLM(거대 언어 모델)** 이 지식에 접근하는 창구로도 활용
	- 서로 다른 레거시 데이터 소스를 매핑하여 하나의 일관된 지식 그래프로 통합하는 효과가 있다.
	- 물리적 시스템을 디지털 형태로 정밀하게 복제한 '디지털 트윈' 구축에도 핵심적인 역할
	- 지식 그래프를 올바르게 구축하려면 데이터의 의미 체계를 정의하는 **온톨로지(ontology)** 모델이 필수적
	- 그래프 데이터를 안정적으로 저장하고 조작하기 위해서는 Amazon Neptune(혹은 neo4j)과 같은 전용 그래프 데이터베이스 필요
