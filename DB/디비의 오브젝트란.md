#DB #dba #oracle #오라클오브젝트
- 오브젝트 즉 **객체**는 오라클 데이터베이스에서 데이터를 논리적으로 저장하고 관리할 때 사용하는 기본적인 단위이다.
- 전부 논리적 의미로 데이터 구조를 체계적으로 할때의 기초가 된다.(사서가 문헌을 나누듯이)
- 오브젝트의 하위 분류에는 아래와 같은 것들이 있다.
- 오브젝트에서 실제 데이터로 저장되는 것들은 데이터 베이스의 저장 위치 관점의 논리적 계층인 세그먼트에 해당한다.(태이블, 인덱스는 세그먼트이기도함, 시퀀스 같이 메모리에 잠시 올라가는건 세그먼트아니고 오브젝트이기만함)
```sql
[Oracle Database]
└─ 1. Schema / User (객체의 Owner) (Segment있음만 무조건 있고 나머진 없음)
      └─ 2. Schema Objects
            ├─ Table
            │     ├─ Table Segment (있을 수도 있음)
            │     └─ Partition / Subpartition 가능
            ├─ Index
            │     ├─ Index Segment
            │     └─ Partition / Subpartition 가능
            ├─ LOB Object (CLOB / BLOB / NCLOB)
            │     ├─ LOB Segment
            │     └─ LOB Index Segment
            ├─ Materialized View
            │     ├─ MV Segment
            │     └─ Partition 가능
            ├─ View
            │     └─ Segment 없음 (가상 객체)
            ├─ Sequence
            │     └─ Segment 없음 (값은 SGA 캐시에 저장)
            ├─ Procedure / Function
            │     └─ Segment 없음 (Shared Pool 저장)
            ├─ Package / Package Body
            ├─ Trigger
            ├─ Synonym (Public / Private)
            ├─ Type / Object Type
            ├─ Directory
            │     └─ OS 경로 Alias
            └─ Database Link
                  └─ 원격 DB 연결 객체
```
- **Table**
	- 데이터를 저장하는 기본 구조
	- **Table Segment**가 실제 데이터를 디스크에 저장
	- Range/Hash/List 등 **Partition 가능**
    
- **Index**
	- 테이블 데이터 검색 속도 향상용 구조, 인덱스 키와 rowid라는 물리적 위치 정보를 가지고 있다.
	- **Index Segment**를 통해 별도 저장
	- Partition/ Subpartition 가능
- **IOT**
	- 인덱스를 PK로 사용하면서 구축한 테이블
	- 인덱스 테이블이 ROWID가 아니라 그 값을 가지고 있음, 그래서 인덱스 스캔을 해도 IO를 한번 씀
	- 컬럼이 많으면 오히려 성능감소
	- 큰 시스템에는 잘 안씀

- **LOB (CLOB / BLOB / NCLOB)**
	- 대용량 문자(텍스트), 동영상/사진 같은 비정형, 코딩 파일 등
	- **LOB Segment + LOB Index Segment**로 구성
	- 테이블 본문 대신 별도 세그먼트에 저장됨

- **Materialized View**
	- 데이터를 실체로 저장하는 View
	- **MV Segment 보유**, Partition 가능
	- Query Rewrite 및 성능 튜닝용

- **View**
	- 쿼리를 저장하는 **가상 테이블**
	- Segment 없음 → 데이터 저장 X

- **Sequence**
	- 유일 번호 생성기
	- Segment 없음 → 값은 딕셔너리에 저장 + 캐시는 SGA 저장
	- 이건 그 좀 특이함 그냥 번호 생성기 프로그램이라 생각하셈

-  **Procedure / Function**
	- PL/SQL 코드 객체
	- Segment 없음 → Shared Pool에 로드되어 실행됨

- **Package / Package Body**
	- 관련 Procedure/Function 묶음
	- 선언부 + 구현부로 구성

- **trigger**
	- 이벤트 기반(INSERT/UPDATE/DELETE) 자동 실행 객체    

- **Synonym**
	- 객체에 대한 별칭 (Public/Private 가능)


- 대표적으로 위와 같은 것들이 존재한다.
